# Inteligentna Waga

## Opis
Inteligentna Waga to nowoczesne urządzenie umożliwiające dokładne ważenie przedmiotów i monitorowanie wyników za pomocą aplikacji.

## Jak działa?
1. Połóż przedmiot na wadze.
2. Waga automatycznie zmierzy ciężar i wyświetli wynik.
3. Dane są przesyłane do aplikacji, gdzie można je śledzić i analizować.

## Funkcje
- Precyzyjny pomiar masy
- Automatyczna synchronizacja z aplikacją
- Historia pomiarów
- Eksport danych

## Jak zacząć?
1. Podłącz wagę do zasilania.
2. Połącz się z aplikacją na telefonie lub komputerze.
3. Rozpocznij ważenie i monitoruj wyniki.
